# Python Sales Automation 🐍📊

Automation project developed with Python, PyAutoGUI, and Pandas to automate a sales reporting workflow.

This project simulates a real business process by automatically:
- Opening the browser
- Accessing Google Drive
- Downloading a sales spreadsheet
- Reading and processing Excel data
- Calculating sales KPIs
- Sending an automated email report

---

# 🚀 Technologies Used

- Python
- PyAutoGUI
- Pandas
- OpenPyXL
- Pyperclip

---

# ⚙️ Features

## Automated Browser Navigation
The script automatically opens the Opera browser and accesses a Google Drive folder.

## File Download Automation
Uses PyAutoGUI to interact with the operating system and download the sales file.

## Data Processing with Pandas
Reads the Excel spreadsheet and calculates:
- Total revenue
- Total quantity of products sold

## Automated Email Reporting
Automatically creates and sends an email containing the sales indicators.
